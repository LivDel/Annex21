## Non-négociables (Chef)
- Amber banner draft ≠ public très visible + badge « Public hors ligne »
- Sections éditeur : profil, contrôles attestés, FR/EN — JAMAIS upload evidence
- Preview auth (draft) ≠ URL publique ; Voir public → 404 si draft
- Publish gated (checklist V1) + modal confirm + toast « Trust publié » → banner « Publié »
- Checklist V1 ONLY : org nommée + ≥1 contrôle attesté + disclaimer (pas de questionnaires acheteurs)
- Public : « Lecture seule · Public » ; empty : « Profil en préparation »
- Zéro preuve brute ; publish jamais auto
- Void soft #05080F, ellipse washes, no orbs, AA muted #CBD5E1
